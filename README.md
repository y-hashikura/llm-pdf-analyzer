# llm-pdf-analyzer

## リポジトリクローン
```shell
git clone https://github.com/your-username/your-repo.git
cd your-repo
```

## 仮想環境作成・有効化
```shell
python3 -m venv .venv
source .venv/bin/activate
```

## 依存パッケージインストール
```shell
pip install -r requirements.txt
```

## .envは各自設定

## APIサーバ起動方法
```shell
uvicorn main:app --reload
```
